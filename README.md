# TERBU

## คลังเอกสาร อมธ. · TUSU document archive

เว็บเก็บเอกสารและข้อมูลชุมนุมของฝ่ายดาต้า องค์การนักศึกษา มธ.
- **เว็บจริง:** https://document-center-513108.web.app
- **Firebase project:** `document-center-513108` ใช้แพ็กเกจฟรี (Spark) **ห้ามอัปเกรดเป็น Blaze**
- **ไฟล์ PDF:** เก็บใน Google Drive โฟลเดอร์ DOCUMENT CENTER
- **ข้อมูล:** เก็บใน Firestore ได้แก่ ชุมนุม เอกสาร โฟลเดอร์ และรายชื่อทีม

## เริ่มทำงาน (ทุกครั้ง)

```
git pull                      # เอางานล่าสุดของคนอื่นมาก่อน
# ...แก้โค้ด...
firebase deploy --only hosting --project document-center-513108   # ขึ้นเว็บจริง
git add -A && git commit -m "บอกว่าแก้อะไร" && git push
```

- **ห้าม `git push --force`** เพราะจะลบงานของคนอื่น
- **repo นี้เป็น Public** ห้าม commit ข้อมูลส่วนบุคคล เช่น เบอร์โทร ลิงก์สำเนาบัตร สมุดบัญชี ไฟล์ Excel ไฟล์สำรอง `tusu-backup-*.json` และไฟล์คีย์ใดๆ (`.gitignore` กันไว้ให้แล้ว)
- **ต้องมีสิทธิ์ก่อน deploy:** `firebase login` ด้วยบัญชีที่มีสิทธิ์ในโปรเจกต์ ถ้ายังไม่มี ขอให้เจ้าของโปรเจกต์เพิ่มให้

## ไฟล์ในโปรเจกต์

| ไฟล์ | ทำอะไร |
|---|---|
| `public/index.html` | โครงหน้าเว็บ ไอคอน และฟอนต์ |
| `public/styles.css` | หน้าตา ธีม (ค่าเริ่มต้นคือ TUSU) โหมดมืด และฟอนต์ |
| `public/app.js` | การทำงานทุกหน้า และข้อความทั้งไทยและอังกฤษ (`TX` อยู่บนสุดของไฟล์) |
| `public/api.js` | ไฟล์เดียวที่คุยกับ Firebase และ Drive |
| `firestore.rules` | ใครอ่านหรือเขียนอะไรได้ deploy ด้วย `firebase deploy --only firestore:rules` |
| `apps-script/Code.gs`, `Upload.gs` | ตัวส่ง เปิด อัปโหลด และลบไฟล์ใน Drive (Google Apps Script) |
| `tools/` | สคริปต์ช่วย: วาดตัวช่วยพิกเซล ([make-sprites.js](tools/make-sprites.js)), รายชื่อชุมนุมกับคำค้น ([club-names.json](tools/club-names.json)), วิธีกู้ข้อมูล ([restore.md](tools/restore.md)) |

[README.web.md](README.web.md) เป็นคู่มือเวอร์ชันแรกที่ยังใช้ข้อมูลตัวอย่าง ใช้ดูโครงสร้างข้อมูลได้ ส่วนวิธีติดตั้งในนั้นเก่าแล้ว

## ระบบที่มีตอนนี้

- **ล็อกอินด้วย Google:**
  - เข้าได้เฉพาะอีเมลที่อยู่ใน Firestore collection `team`
  - Document ID คืออีเมล และมี field `role` เป็น `viewer` หรือ `editor`
  - เพิ่มสมาชิกได้ใน Firebase console
- **ชุมนุม 115 รายการ:**
  - กรองตามวิทยาเขต สาย หรือสถานภาพได้
  - ชื่อตรงกับใบแต่งตั้ง 2569 (ตรวจแล้ว 72 ใบ)
  - มีคำค้น (`keywords`) ทั้งชื่อเดิม ชื่ออังกฤษ และชื่อเล่น
- **คลังกลาง:**
  - โฟลเดอร์ 16 สี
  - อัปโหลด 3 ขั้น ไฟล์ขึ้น Drive โดยอัตโนมัติ
  - ถังขยะใช้วิธีย้ายไฟล์ไปถังขยะของ Drive
- **หมวดหมู่ที่เชื่อมกัน:**
  - ดูได้ที่ `#tags`
  - หัวข้อจัดให้อัตโนมัติจากชื่อชุมนุม (ดู `TOPICS` ใน app.js)
  - มี "ที่เกี่ยวข้อง" ทั้งในหน้าชุมนุมและหน้าเอกสาร
- **ตะกร้าไฟล์:** รวมเป็น PDF เดียว พิมพ์ แปลงเป็นรูป หรือโหลดเป็น ZIP
- **ระบบพิมพ์:** พิมพ์ได้ทุกไฟล์ และกด Ctrl+P ตอนเปิดไฟล์อยู่ก็ได้
- **ไฟล์ส่วนตัว:** เก็บในเบราว์เซอร์ของเครื่องตัวเอง
- **ถามน้อง:** แชทตอบจากข้อมูลในเว็บเท่านั้น ไม่ใช้ AI
- **ตัวช่วยพิกเซล:** มีน้องดาต้า น้องหมา และน้องบอท เพิ่มรูปเองได้และทั้งทีมใช้ร่วมกัน เปลี่ยนตัวได้ที่หน้าหลัก
- **ธีมและฟอนต์:** ฟอนต์ค่าเริ่มต้นเป็น Kanit กับ Noto Sans Thai เลือกเองได้ในหน้า "ตั้งค่าหน้าตา"
- **หน้า "วิธีใช้":** อยู่ที่ `#help`
- **ปุ่มสำรองข้อมูล:** อยู่ในตะกร้าไฟล์ เห็นเฉพาะ editor

## ข้อควรรู้

- **Apps Script:** ถ้าแก้ `Code.gs` หรือ `Upload.gs` ต้องไปวางโค้ดใน Apps Script editor แล้วกด Deploy → Manage deployments → **New version** ทุกครั้ง URL ใน `api.js` (`FILE_SERVER`) ห้ามเปลี่ยน ไฟล์ใน repo อาจไม่ตรงกับเวอร์ชันที่ deploy อยู่ ให้เช็กใน editor ก่อนแก้
- **Cache:** html/js/css ตั้งเป็น `no-cache` แล้ว deploy เสร็จทุกคนจะเห็นของใหม่ทันที
- **ข้อความในหน้าเว็บ:** แก้ที่ `TX.th` และ `TX.en` ใน app.js ต้องแก้ทั้งสองภาษา

- "ชุมนุมเคส" ยังไม่มีคำค้น
